# Tuppy 安全文档

> 状态：v0.1 鉴权已实现（Flask 登录页）。无外部传感器、无模型调用，威胁面小；v0.3 接安卓通知后按架构文档 4.5/4.6 扩展。

## v0.1 威胁模型

| 威胁 | 现状 | 对策 |
|---|---|---|
| 页面被外部访问 | 全家数据在 VPS 上 | Flask 登录页 + session cookie（30 天），未登录 302。`/static/` 免鉴权（PWA 资产） |
| 密码泄露 | 单密码 | `.env` TUPPY_PASSWORD（随机 hex），hmac.compare_digest 比对 |
| 密码爆破 | 登录页无频率限制 | 单人 + 随机 16 字符密码，风险可接受。必要时加失败延迟 |
| 数据丢失 | SQLite 单文件 | 每日备份轮转 7 份 |
| 导入脏数据 | CSV/ICS/JSON 任意解析 | 预览确认 + 失败行汇总 + 规则导入校验（template/kind 白名单） |
| 注入 | 自用单用户 | 参数化 SQL 为默认 |
| 部署触发 | 页面"更新"按钮 | www 只写 trigger 文件，root cron 捡信执行。零权限扩张 |

## 已弃用

- Basic Auth：PWA standalone 弹窗缺陷、无登出、无过期。2026-08-16 换 Flask 登录页。

## v0.1 明确不涉及

- 无外部传感器 → 无原文出设备问题
- 无模型调用 → 无数据过第三方
- 无多用户 → 无权限矩阵

## 未来版本安全承诺（从架构文档继承）

- 原文不出边缘层
- 出站必过脱敏闸
- 隐私一断全断
- 提议默认可逆
- 打扰有预算
