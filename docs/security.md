# Tuppy 安全文档

> 状态：骨架。v0.1 无外部传感器、无模型调用，威胁面小；v0.3 接安卓通知后按架构文档 4.5/4.6 扩展。

## v0.1 威胁模型

| 威胁 | 现状 | 对策 |
|---|---|---|
| 页面被外部访问 | 全家数据在 VPS 端口上 | Basic Auth（release.md） |
| 密码泄露 | 单密码 | 存 .env，不进 git |
| 数据丢失 | SQLite 单文件 | 每日备份轮转 7 份 |
| 导入脏数据 | CSV/ICS 任意解析 | 预览确认 + 失败行汇总 |
| 注入 | 自用单用户 | 参数化 SQL 为默认 |

## v0.1 明确不涉及

- 无外部传感器 → 无原文出设备问题
- 无模型调用 → 无数据过第三方
- 无多用户 → 无权限矩阵

## 未来版本安全承诺（从架构文档继承）

- 原文不出边缘层
- 出站必过脱敏闸
- 隐私一断全断
- 提议默认可逆
- 打扰有预算
