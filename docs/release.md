# Tuppy 发布文档

> 状态：骨架。

## 版本规则

- v0.x 语义：x = 阶段（0.1 值守 / 0.2 推送 / 0.3 安卓……）
- 每版本完成判据：见该版本设计文档"完成的定义"章节
- 达成后写 CHANGELOG，记录实际数据（接受率、运行天数）

## 发布流程

1. 版本设计文档定稿（本仓库 docs/）
2. 实现 + 测试通过（见 testing.md）
3. 部署 VPS，跑满判据天数
4. 记录实际数字进 CHANGELOG
5. 由使用摩擦决定下一版本方向

## 部署

- systemd 托管 Flask 进程
- nginx 反代 + Basic Auth
- crontab 两班
- DB 每日备份轮转 7 份
