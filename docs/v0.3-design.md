# Tuppy v0.3 设计文档

> 状态：**进行中**。主目标：ESP32 一体机（桌宠 + 看板 + 语音录入）。
> v0.2 观察项在下文 §2 持续跟踪。

## 1. 主目标：ESP32 一体机

ESP32-S3 已刷小智固件（xiaozhi-esp32，开源语音助手，带麦 + 喇叭 + 屏）。三合一：

- **桌宠**：呼吸灯状态显示（在场层）
- **看板**：屏上查看推送/提议/待办
- **语音录入**：说话记数据（解决最大摩擦：录入）

### 1.1 待设计问题

- **与 VPS 通信**：MQTT（xiaozhi 自带）vs HTTP 轮询 vs WebSocket。双 topic 设计（announce 单向 / conversation 双向）之前定过，v0.3 落地
- **看板内容**：屏上显示什么？提议列表？健康灯？简化版周报？
- **语音录入格式**："记一笔，物品，牛奶，8月20号到期"——怎么解析到域/分类/日期？小智对话流复用 vs 独立唤醒词
- **桌宠灯态**：颜色语义定稿（绿=干活/蓝=有摘要/黄=有事找你/红=隐私）
- **物理隐私开关**：双键设计（一红断听、一黄闭嘴）之前讨论过
- **固件改不改**：小智现成固件直接用，还是改固件加 Tuppy 专属功能？改固件成本高（ESP-IDF 开发），先用现成固件 + 服务器端适配

### 1.2 已定（继承前期讨论）

- ESP32 = 在场层 + 语音交互层，家庭广播走 MQTT（"爸，该吃药了"）
- 广播受打扰预算管（语音打扰性比推送强十倍，默认静音档）
- 语音通道预算：v0.2 预算器结构已留打断级空位
