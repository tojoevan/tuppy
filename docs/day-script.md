# 剧本：它的一天（v0.1）

> 只写一件事：用户打开 web 会看到什么。
> 它叫"小 M"——名字用户可改。它说话风格固定：短句、第一人称、说事实、给选择。
> 【后台】= 用户看不到的系统动作。

## 前一天晚上

我在 web 上录了家里数据：

- **账本**：最近 3 天支出
- **日程**：本周安排（周四 14:00-16:00 季度评审会）
- **健康**：妈上周血压记录，昨天缺测
- **疫苗**：女儿乙脑第二针，周四 15:00

录完就睡了。

我打开手机浏览器：

```

  小 M · 早班 07:00
================================

早。你睡的时候我看了下家里的事，
两件想跟你说：

· 周四的疫苗撞了你的评审会
  疫苗 15:00，评审会到 16:00
  要记着吗？等你联系社康改时间
                        [记下]  [不用]

  要我记下"今晚问妈"吗？
                        [记下]  [不用]
```

我点了两个"记下"。

```
好，两件都记在待办里了。
```

【后台】系统记下：我关心疫苗、关心妈的血压。

## 晚上 21:30

我打开页面：

```

  小 M · 待办

你记的两件事：

□ 联系社康改疫苗时间（周四前）

```
记下了。140/88，正常范围。

## 分寸（为什么这样写）

- **它说"我"，但不说"想你"**：第一人称给存在感，感情词不给。卖行为不卖感情。
- **开场白有节律**："早班""交班"——像同事上下班，不是 24h 随机出现。
- **它说自己学到什么**："我学到的""下周说准一点"——让用户看得见它成长。
- **它显示记忆**："你上周改过时间，我没忘"——mate 感来自它记得你的事。
- **每句都可核验**：它说的每条都带事实（数字、时间、谁）。用户能查对错。
- **不谄媚**：它不夸用户，只汇报和干活。可靠来自胜任，不来自表演。
