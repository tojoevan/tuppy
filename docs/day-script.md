# 剧本：用户的一天（v0.1）

> 只写一件事：用户每天打开 web 会看到什么。
> 【后台】= 用户看不到的系统动作，用括号标注。

## 第一天之前

昨晚，我在 web 上录入了家里数据：

- **账本**：最近 3 天支出
- **日程**：本周安排（周四 14:00-16:00 季度评审会）
- **健康**：妈上周血压记录，昨天缺测
- **疫苗**：女儿乙脑第二针，周四 15:00

录完就睡了。系统晚上自己跑了一次。

## 早上 07:15

我打开手机浏览器，看到这个页面：

```
================================
  今早 3 件事
================================

① 周四疫苗预约撞了评审会
   疫苗是周四 15:00
   你的评审会是周四 14:00-16:00
   [记到待办：联系社康改时间]  [忽略]

② 妈的血压昨天没记
   连续 1 天缺测
   [记到待办：今晚问妈]        [忽略]

────────────────────────────
  其它没打扰你的事：1 件
  （电费比上月高 40%，数据还太少，先记着）
```

我点了①和②的"记到待办"。

【后台】系统把两条反馈记下：我关心疫苗、关心妈的血压。

## 晚上 21:30

我打开页面，看到待办列表：

```
================================
  待办
================================
□ 联系社康改时间（疫苗撞评审会）
□ 今晚问妈血压
```

去问了妈：140/88，正常。回到页面，把数字填进健康表单，勾掉待办。

【后台】系统看到：缺失补上了，数值正常。这件事归档。

## 晚上 22:00

页面多了一个"它今天看到什么"入口。我点开：

```
================================
  影子报告（第 1 天）
================================
今天它处理了 9 条记录，只说了 2 条。

没说但记着的：
· 电费比上月高 40%（数据少，先看一个月）
· 女儿奶粉买得比上月勤（数据少）
· 周五家长会没写地点（不知道该不该提醒）
```

我看完，关了页面。

## 一周后（第 7 天）

页面出现第一个统计数字：

```
================================
  本周
================================
提议 14 条
你接受 8 条，忽略 5 条，拒绝 1 条

它注意到了：
"临期提醒"你 4 次忽略了 4 次
→ 已自动降级：以后临期只记录，不单独提醒
```

## 一个月后（第 30 天）

早上打开页面：

```
================================
  今早 2 件事
================================

① 这个月电费比上月高 38%
   上月 287，本月 396
   [记到待办：查一下电表/电器]  [忽略]

② 疫苗周四 15:00（3 天前你改过时间）
   [知道了]  [忽略]

────────────────────────────
  其它没打扰你的事：12 件
```

第一条"电费"是它第一次主动说统计异常——因为今天数据满 30 天，它才敢说。

## 剧本里的规则（一句话版）

- **第一天只提醒"明摆着的事"**：撞时间、缺记录。数据少，不说"异常"。
- **点"记到待办" = 你说"这个重要"**，它记下来，以后这类事优先说。
- **忽略 4 次 = 自动闭嘴**，以后这类只记录不提醒。
- **"它今天看到什么"从第一天就有**：你可以随时核对它挡了什么、为什么。
- **数据满 30 天才说"异常"**：比如电费。规则写死，不是它自己发挥。
