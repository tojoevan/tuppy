# Tuppy 测试文档

> 状态：骨架。v0.1 开发时填充用例。

## 测试策略

三层：

1. **单元测试**（pytest）：规则引擎每个模板的触发/不触发边界
2. **集成测试**：cron 班次脚本对 SQLite 的读写正确性
3. **手工验证**：剧本走查——按 day-script.md 的 Day 1 流程人工过一遍
